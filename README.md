## О проекте

Проект реализует сверточную нейронную сеть (CNN) для классификации
10 классов изображений одежды и обуви из датасета
[Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist).

Реализовано:

- автоматическая загрузка датасета (при первом запуске);
- нормализация изображений;
- разбиение train-выборки на train/val в пропорции 90/10;
- обучение CNN с `CrossEntropyLoss` и оптимизатором `Adam`;
- сохранение лучшего чекпоинта по `val_accuracy`;
- оценка на тестовой выборке, confusion matrix, примеры предсказаний;
- предсказание для произвольного изображения без повторного обучения.

Стек: **Python 3.13, PyTorch, torchvision, scikit-learn, matplotlib, Pillow**.

## Обучение

```bash
python train.py
```

Все параметры — через аргументы командной строки:

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--epochs` | `10` | Количество эпох |
| `--batch-size` | `64` | Размер батча |
| `--lr` | `1e-3` | Learning rate для Adam |
| `--val-split` | `0.1` | Доля валидационной выборки |
| `--seed` | `42` | Random seed для воспроизводимости |
| `--data-dir` | `data` | Папка для датасета |
| `--models-dir` | `models` | Папка для чекпоинтов |
| `--results-dir` | `results` | Папка для графиков и метрик |
| `--cpu` | — | Принудительно использовать CPU |

Пример с другими гиперпараметрами:

```bash
python train.py --epochs 15 --batch-size 128 --lr 5e-4 --seed 7
```

В процессе обучения в консоль выводятся `train_loss`, `val_loss`, `val_acc` для каждой эпохи.
Лучший чекпоинт сохраняется в `models/best_cnn.pth` (по `val_accuracy`).
История обучения пишется в `results/history.json` и `results/history.csv`.

## Оценка качества

```bash
python evaluate.py
```

Скрипт:

1. загружает `models/best_cnn.pth`;
2. считает `loss` и `accuracy` на тестовой выборке;
3. строит `results/loss.png` и `results/accuracy.png` по истории обучения;
4. строит `results/confusion_matrix.png`;
5. сохраняет `results/samples.png` — 8 случайных тестовых изображений с предсказанием и истинным классом;
6. пишет итоговые метрики в `results/test_metrics.json`.

Тестовая выборка **не используется** при обучении и подборе гиперпараметров — только для финальной оценки.

## Предсказание для одного изображения

```bash
python predict.py --image path/to/image.png
```

Скрипт загружает сохранённую модель, применяет ту же нормализацию,
что при обучении, и печатает:

- предсказанный класс;
- вероятность для этого класса;
- вероятности для всех 10 классов.

Чтобы быстро получить тестовую картинку:

```bash
python -c "from torchvision import datasets; ds = datasets.FashionMNIST('data', train=False, download=True); img, label = ds[0]; img.save('test_img.png'); print('label =', label)"
```

## Архитектура модели

CNN реализована с нуля на базовых компонентах `torch.nn` — без предобученных весов.

| # | Слой | Параметры |
|---|---|---|
| 1 | Input | 1 × 28 × 28 |
| 2 | Conv2d + ReLU | 16 фильтров, 3×3, padding=1 |
| 3 | MaxPool2d | 2×2 |
| 4 | Conv2d + ReLU | 32 фильтра, 3×3, padding=1 |
| 5 | MaxPool2d | 2×2 |
| 6 | Flatten | → 1568 |
| 7 | Linear + ReLU | 128 нейронов |
| 8 | Linear | 10 выходов |

## Результаты



**Итоговая точность на тестовой выборке:** `0.9177`
**Test loss:** `0.2655`

### Графики

- `results/loss.png` — динамика `train_loss` и `val_loss` по эпохам
- `results/accuracy.png` — динамика `val_accuracy`
- `results/confusion_matrix.png` — матрица ошибок по 10 классам
- `results/samples.png` — примеры предсказаний

### Наблюдения

- Модель показывает быстрый рост `val_acc` в первые 4–5 эпох (с 0.869 до 0.912). После 5-й эпохи темп роста замедляется, и кривая выходит на плато (небольшой прирост до 0.924 к 10-й эпохе).
- На графике потерь чётко виден момент начала переобучения. После **7-й** эпохи `val_loss` достигает своего минимума и начинает расти, в то время как `train_loss` продолжает падать. Это говорит о том, что модель начинает зазубривать тренировочную выборку и теряет способность к обобщению. Благодаря сохранению лучшего чекпоинта по `val_acc`, мы используем веса именно с 7-й эпохи, избегая негативного влияния переобучения.
- **Анализ матрицы ошибок:** 
  - Отлично классифицируются классы с уникальным силуэтом: Брюки (983), Сандалии (989) и Сумки (990).
  - Основные ошибки возникают внутри группы похожей верхней одежды. Самые частые перепутывания: `T-shirt/top` и `Shirt` (120 и 77 ошибок соответственно), `Shirt` и `Coat` (66 ошибок), а также `Pullover` и `Coat` (52 ошибки). Это объясняется низким разрешением изображений (28×28 пикселей) и схожестью силуэтов этих предметов одежды.
  - Также наблюдается незначительная путаница в обуви между `Sneaker` и `Ankle boot` (36 и 21 ошибка).

## Ограничения и идеи улучшения

**Ограничения текущей модели:**

- Небольшая сеть (16/32 фильтра) — низкая ёмкость;
- нет `BatchNorm` и `Dropout` → склонность к переобучению;
- нет аугментаций → модель не устойчива к сдвигам/поворотам;
- фиксированный `lr` без scheduler'а.

**Идеи улучшения:**

- Добавить `BatchNorm2d` после свёрток и `Dropout` перед `Linear`;
- Аугментации: `RandomHorizontalFlip`, `RandomCrop(28, padding=2)`, `RandomRotation`;
- `ReduceLROnPlateau` или `CosineAnnealingLR`;
- Увеличить число фильтров (32/64) и добавить третий свёрточный блок;
- Попробовать TTA (test-time augmentation);
- Полноценный `StratifiedKFold` вместо `random_split` для более честной валидации.

## Воспроизводимость

Все случайные генераторы фиксируются в `train.py` (`set_seed`):

- `random.seed(seed)`
- `numpy.random.seed(seed)`
- `torch.manual_seed(seed)`
- `torch.cuda.manual_seed_all(seed)`
- `torch.backends.cudnn.deterministic = True`
- `torch.backends.cudnn.benchmark = False`

`random_split` для train/val использует собственный `torch.Generator`, засеянный тем же `seed`.

Для полного воспроизведения эксперимента:

```bash
python train.py --seed 42
```

При одинаковом seed и одинаковом окружении результаты будут совпадать в пределах
небольших флуктуаций (связанных с CUDA-недетерминизмом на некоторых GPU).
